This is a modification of the [Aeroscapes/Aero Islands](https://modrinth.com/mod/aeroscapes-islands) Mod for Minecraft 1.21.1 by [Nuclear Obelisk](https://modrinth.com/user/nuclearobelisk) that is being built for the Ultima Draconis Modpack. My goal is to create a Dimension Version of the mod, for use in Ultima Draconis.

It is being built off version 1.1.1 of Aero Islands.
